## 🔧 Projects

### ⚡ Smart Energy Meter
> `STM32` · `PZEM-004T` · `UART` · `Modbus RTU` · `MQTT` · `Node-RED`

Real-time energy monitoring system built around the STM32 microcontroller and the PZEM-004T sensor module.

- Measurement of voltage, current, active power and energy consumption
- Low-level UART communication with the PZEM-004T, including custom CRC-16/Modbus implementation and byte-level register parsing
- Data published to a Mosquitto MQTT broker
- Live visualization dashboard built with Node-RED (real-time curves, consumption tracking, threshold alerts)

---

### 🤖 IoT Bot
> `STM32` · `ESP32` · `I2C` · `ADC` · `UART` · `Bluetooth` · `WiFi` · `MQTT`

A dual-microcontroller IoT system combining local embedded sensing with cloud connectivity.

- Embedded layer: I2C temperature sensing (DS1621), 3-channel ADC, Bluetooth serial (HC-06), motor control via L298N with PWM
- Connectivity layer: STM32 → ESP32 data forwarding over UART; ESP32 acts as WiFi client
- Sensor data published to both ThingSpeak and a Mosquitto MQTT broker
